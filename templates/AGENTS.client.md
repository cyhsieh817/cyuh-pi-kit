# Client workspace rules (optional)

Copy this file to the client project root as `AGENTS.md` (or merge the section below).
It pairs with `@cyuh/pi-kit` auto-continue so weak/local models finish deliverables.

## Deliverable write discipline

1. Before overwriting an existing deliverable, **read it back**.
2. Never replace a longer/complete draft with a shorter mid-sentence or colon-truncated draft.
3. After write, **read the file again** and verify sections are complete.
4. When the task is done, reply with one line only: `path + size + complete`.
5. If blocked on a user decision, stop and ask **one** clear question — do not pretend the file is finished.

## Task completion

- Prefer tools until the original request is verified complete.
- Do not stop after narrating a plan (“next I will…”) without doing the work.
- Empty final messages after tool calls are incomplete — continue until verified.
